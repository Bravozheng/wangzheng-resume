# 体检到店履约｜即时动态展示规划 v2

## 本轮修订目标

1. 左侧标题与右侧内容共用同一顶部起始线。
2. 明确标出线上预约、到店签到和报告解读中的当前进程。
3. 将顶部提示与展开详情组织为一段连续、可循环的交互序列。
4. 放大组件保持同一宽度、同一中心轴和原始宽高比。
5. 使用新的到店导引场景，避免连续页面重复同一背景。

## 页面栅格

- 左侧标题：单行“提高到店履约效率”，不折行。
- 左侧流程：当前进程 02 / 03；预约完成 → 到店签到 → 报告解读。
- 中部手机：固定在 1240 × 515，显示尺寸 600 × 1297。
- 右侧组件：固定宽度 1280，中心轴 y = 1110，所有素材等比缩放。
- 左右标题顶部：共同从 y = 180 的视觉起始线进入。

## 动态节奏

- 顶部精简提示停留 1.5 秒。
- 点击反馈通过四帧扩散圆环完成，总时长约 0.5 秒。
- 组件在同一位置交叉过渡至展开状态。
- 展开详情停留 1.9 秒。
- 以较短过渡收起，回到精简提示并循环。

## 背景语义

新背景使用现代体检机构入口、地面导引光带和定位节点表达“接近机构与到店确认”。左侧保持暗色留白，右侧形成空间纵深。背景不出现人体器官、手机、界面卡片、品牌文字或可读标识。

## 校验标准

- 手机主体像素与用户原始导出图等比缩放结果一致。
- 放大组件固定为 1280 px 宽，禁止横向或纵向拉伸。
- 组件中心轴固定，切换状态时不发生横向跳动。
- 左右主标题顶部对齐；左侧标题保持单行。
- 当前流程节点和当前提醒状态可在首次浏览时快速识别。
