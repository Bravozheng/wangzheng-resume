# 正式网页：静态稿与交互映射 v1

这份清单是正式网页的唯一实施基线。页面只能还原下列已确认视觉稿；历史版本、临时探索稿和当前网页里自行新增的视觉结构均不进入正式页面。

## 共同规则

- 桌面母版：1920 × 1080，对应 3840 × 2160 的 4K 静态稿。文字、图片、线条和留白按母版坐标等比换算。
- 网页内容由 HTML 文字、CSS 图形与独立图片素材组合，4K 整屏图只用于视觉对照，不作为页面背景直接铺贴。
- 每一屏保持满视口连续滚动。只有静态稿中已确认的按钮、分页、Tab 或局部切换可以引入交互。
- 锚链接负责屏与屏之间的连续跳转；同一屏的多状态通过 Tab、卡片或箭头切换，不拆成重复的连续页面。
- “向下探索”沿用已确认的双层细环与柔和呼吸光，减少动态偏好时停止呼吸动画并保持常亮。
- 不新增固定大导航、项目计数、悬浮卡片、渐变装饰、阴影或解释性模块。全局导航只能以不改变静态稿构图的轻量方式出现。
- 桌面视觉验收尺寸：1920 × 1080 与 1440 × 810；移动端验收尺寸：430 × 932 与 390 × 844。

## 验收方式

1. 每完成一屏，在 1920 × 1080 截图并与对应静态稿叠加或并排检查。
2. 检查主标题、正文、图片边界、基线、留白、色值和主要线条；出现明显偏移即继续修改。
3. 验证锚链接、Tab、箭头、键盘操作、视口触发与减少动态偏好。
4. 四页全部通过桌面和移动端尺寸检查后，才进入发布整理。
