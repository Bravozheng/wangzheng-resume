状态：内容规划已于 2026-10-12 获得用户确认。第一段“报告提醒”已根据反馈合并为单屏表达。第二段“阅读转变”与第三段“结构重构”已重新生成连续双屏：第一屏以三条结构映射基线说明旧阅读方式如何转向人体化阅读；第二屏使用结构图例与完整人体报告解释三层新结构。等待视觉确认。

## 来源与章节关系

本段承接已暂定确认的“提高到店履约效率｜即时动态”第三版，沿 PDF 第31—33页展开。三个连续段落分别承担报告提醒、阅读问题与转变、可视化结构解析。允许扩展成多个滚动状态，不把三页材料压入同一屏。

章节核心：让用户知道报告已生成，快速找到需要关注的内容，并建立人体定位、异常指标和专家解读之间的阅读关系。

## 第一段：报告生成后，先告知，再保留入口

对应 PDF 第31页。

内容关系：

1. 报告已产出，用户登录平台首页。
2. 首页浮层优先告知，强化报告解读引导。
3. 用户暂不查看时，首页仍提供常驻轻提示入口。
4. 常驻提示包含报告状态、日期与未解读时间，支持再次进入解读。

画面：同屏并列呈现“检后提醒01.png”和“首页状态提示位.png”，中间仅保留简洁的状态承接关系。两种状态共同组成一套报告提醒机制；不再拆成两屏，也不提取局部放大。浮层保持原稿结构占位，不向原界面填入未提供的文案。

动态：后续只需表现浮层告知退出后，首页常驻提示继续承接；不把两个状态扩展成独立章节，不表现未经证实的反复弹窗频率。

## 第二段：报告线上化之后，理解门槛仍然存在

对应 PDF 第32页，并为第33页的人体报告提供引子。

先说明“纸质报告电子化”和“降低阅读门槛”之间尚存的问题：

| 原有阅读问题 | 设计方向 |
| --- | --- |
| 文字与数值分散，异常项易被忽略 | 汇总需关注内容，形成异常项卡片 |
| 专业指标难以理解其位置与意义 | 用人体系统建立阅读上下文，并保留具体指标与趋势入口 |
| 医学生理结构陌生，解读可信度需要支撑 | 结合人体定位与明确的专家解读入口 |

画面：电子纸质报告作为较小的依据图；电子列表作为原有线上结构；新人体报告作为后续主视觉。通过滚动先解释问题，再让新报告接替主要阅读位置，避免三张同尺寸手机平均分配视觉焦点。

纸质报告与新报告来自不同样例，仅比较信息组织方式；不将纸质报告中的数值逐条转换为新报告示例数据。

## 第三段：先定位，再看指标，最后进入解读

对应 PDF 第33页。

| 新结构层级 | 原始界面对应位置 | 需要解释的作用 |
| --- | --- | --- |
| 人体指标呈现 | 上半部人体系统标签、标记点与异常数量 | 建立异常所属系统的空间关系 |
| 异常项卡片展示 | 中部需关注项、卡片、指标与趋势 | 从总览进入具体关注内容 |
| 专家解读入口 | 下半部专家区域、音频与图文/语音入口 | 将指标阅读接到有明确专家信息的解读 |

画面：人体可视化报告保持完整、最大且清晰；原列表与新结构示意作为辅助。用三组对齐的注解对应三个区域，勾线只指向当前被解释的位置，三个区域不同时堆叠高亮。

动态：在作品集的结构注解中选择“人体指标 / 异常卡片 / 专家解读”，同步高亮完整手机中的对应区域。这是作品集的阅读辅助，不改写原产品的内部交互。

段落收束候选：将分散指标重新组织为“人体定位—异常聚焦—专家解读”的连续阅读路径。

## 背景方向

建议使用新的“医学信息解析空间”：低对比的半透明医学成像层、人体系统轮廓与少量指标定位点，主体放在右下方。深蓝底色与青绿色强调延续前章，局部采用雾蓝与冷白呼应人体报告原界面。

第一段背景较安静，承托提醒状态；随后医学分区与成像层逐步成为阅读转变的背景依据。背景只负责主题与纵深，不承担具体数据、不显示诊断结论，不与前景原始人体图争夺焦点。
