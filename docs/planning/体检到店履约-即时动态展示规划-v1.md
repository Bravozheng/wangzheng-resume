# 体检到店履约｜即时动态展示规划 v1

## 章节定位

- 章节目标：承接线上预约完成后的线下到店环节，说明如何通过即时动态提高到店信息的可见性。
- 核心叙事：预约之后，服务继续；同一组到检信息根据使用场景切换呈现形态。
- 页面关系：延续上一章节的深色方案展示语言，保留标题栅格、青绿色强调色与医疗空间氛围；本章节以固定手机位置和状态切换形成新的阅读节奏。

## 信息结构

左侧保持稳定，只承担章节总述与服务节点定位：

1. 提高到店履约效率
2. 即时动态
3. 预约之后，服务继续
4. 服务节点：体检预约 → 到店签到 → 报告解读
5. 展示形态：锁屏签到提醒、顶部精简提示、按需展开详情

中部手机始终使用同一尺寸与坐标，用完整源图说明真实显示状态。右侧放大对应组件，并解释该状态承载的信息重点。

## 滚动与状态切换

1. 手机位置、尺寸和页面标题保持稳定。
2. 随滚动依次切换锁屏提醒、顶部精简提示和展开详情。
3. 手机状态切换时，右侧组件同步替换；不叠放多个手机，不产生残影。
4. 报告提醒作为本章节末尾的检后衔接状态，用于引向后续报告解读内容。

## 素材与边界

- 所有手机界面直接使用用户提供的完整导出图，不重绘、不裁切、不增加设备外壳。
- 四张手机图统一显示宽度 600 px，按源图比例等比缩放至 600 × 1297 px。
- 独立组件中的白色区域属于原稿结构占位，实际显示内容以完整手机图为准。
- 本轮只表达现有素材能够证明的提醒形态，不增加排队、导航、自动签到、算法触发或结果数据。
