# 第三部分：内容与构图执行规划

日期：2026-10-13。版本：v2，强化创意、专业感与管理者视角。状态：供用户确认的构图规划；本轮不制作视觉稿、HTML或动态原型。

本文件细化 `管理与技术拓展-章节规划与文案-v4.md`，作为下一轮静态构图的执行提案。前两个项目保持最新已确认视觉效果。

## 视觉方向：资源编排与制作工作台

用户最新要求：第三部分需要更有创意，同时体现专业感与管理高级感。

推荐采用**资源编排与制作工作台**的视觉方向，结合编辑式排版。借原稿UED书架、资源入库和九步生产的内容，把素材类别、生成过程及业务成果构成同一个可阅读的展陈空间。工作台是作品集的构图方式，不补造一个实际已上线的内部管理系统。

### 三种方向的取舍

| 方向 | 优点 | 表现侧重 |
| --- | --- | --- |
| 资源编排与制作工作台（推荐） | 创意来自资源与流程的真实关系，能同时表现整体统筹与具体技术实践 | 资源归类、方法组织、业务输出 |
| 编辑式管理档案 | 文字、比例与留白具有较强秩序，方便快速阅读职责与决策 | 管理说明与关键证据 |
| 生成实验室 | 适合深入展示模型、生成过程和问题修正 | 技术理解与制作过程 |

主方向采用第一种，排版采用第二种的秩序，技术展开采用第三种的过程细节。三者服务同一套版式，不拼成三套风格。

### 创意集中在一个主视觉关系

开场将少量真实角色、医疗图形、营销资源和视频关键帧放在同一资源工作面中，按层级与类别组织。读者先看到整体，再逐步进入资源、方法与成果。立体感由柔和透视、浅厚度和留白形成，截图内容保持正面、等比且完整。

后续模块沿同一组资源的身份继续展开：02归类资源，03查看生成方法，04查看业务应用，05进入视频制作，06阅读规则和经验。每次转换都保留清楚的对象关联。

### 管理感来自信息取舍

- 开场明确负责人身份与工作目标，核心文案有足够尺寸和空间。
- 总览表达负责的资源与生产范围，细节按阅读动作展开。
- 目标、方法、阶段输出和本人职责紧邻呈现，读者能核对责任与成果。
- 所有内容不平权：主案例、代表资源与决策说明有明确的大小比例。
- 每个模块留出安静区域，细节集中在核心内容附近，不把页面铺成工具清单。

### 视觉体系提案

| 用途 | 色值 | 使用方式 |

| 石墨工作区 | #242833 | 开场、视频制作与方法沉淀背景 |

颜色是首轮试稿提案，不是新的已确认视觉基准。原素材本身的丰富颜色完整保留，基础色负责稳定画面。

字体继续采用Helvetica/Helvetica Neue和中文无衬线。标题用字号、字重、字距和构图比例形成设计感，斜体只用于确有强调意义的短语。基线、图例间距和阅读顺序与前两部分保持一致。

### 动态的表达任务

第一次进入开场时，可以做一次资源由成组排列到整体归类的轻量编排；静态终态应完整成立，不持续悬浮或反复移动。

选择资源类别、展开制作阶段时，在同一工作面中聚焦当前内容，保留阶段名称或源资源的锚点。动效解释“正在看哪一层、当前内容来自哪里”。所需效果优先使用平面布局与轻量变换表达，网页实现不强制依赖复杂3D场景。

关键字、数据和说明保持稳定。视频主动播放，详细证据主动展开，重点不会被自动切换藏起来。

## 1. 核心表达

章节名称：**设计管理与技术拓展**。

与体检结尾已确认的“资源成本与团队建设”入口对应：第三部分开场保留该名称作为章节说明，主视觉用下方核心标题表达。原入口无需为此改稿。

核心标题：**让设计能力，成为团队的持续生产力。**

角色：**UED资源体系与AI视频流程负责人**。

角色说明：**牵头设定目标与方向、组织推进并作出最终决策；共同参与执行，负责成果提炼与方法总结。**

阅读结束后，访客应理解三个结论：

1. 本人能组织设计资源的持续建设，使资源服务多个业务场景。
2. 本人能把AI实践组织成有步骤、有中间产物、有人工判断的制作流程。

管理能力以本人明确的职责及具体行动呈现。AI理解以业务适配、生成控制、流程组织、质量判断呈现。团队成果、本人责任和技术作用彼此对应。

## 3. 七个模块的构图提案

### 01 开场：先认清负责人角色

**标题**：让设计能力，成为团队的持续生产力。

**说明**：统筹UED资源建设与AI视频生产，从目标规划、组织推进到最终决策和方法沉淀。

**角色行**：UED资源体系与AI视频流程负责人。

**首要焦点**：核心标题。副说明和角色行紧密成组，不另外摆放一个个人职责大卡片。

**主画面**：原资源中的代表角色、医疗图形、营销画面与视频关键帧，在同一个资源工作面中成组编排。采用柔和透视与浅层厚度，建立整体统筹的空间观感；素材数量少、主体清楚，图例内容保持完整。

**管理表达**：定方向、组织推进、参与落地、最终决策、提炼总结，以一组平面文字呈现；下方原管理方向仍可作为阅读导航：效能优化、团队建设、业务深耕、对外发声。两组不同时放大，优先负责人职责，原方向作为正文中的简洁概括。

**版式**：左侧大字与职责，右侧一组资源主视觉。保留与前两个首屏统一的角落页眉规范；后续内容屏不重复角落个人与公司信息。

**来源**：35—36页及用户已确认职责。

### 02 资源体系：看见建设内容与复用关系

**标题**：让资源可复用，让输出有标准。

**说明**：创建、维护与扩容角色、医疗图形和营销资源，支持后续业务应用。

**本人职责**：我牵头规划资源建设的目标与方向，组织推进，并共同参与执行支持。

**首要焦点**：真实资源总览。左侧文案简洁，右侧展示承担主要视觉重量。

**主画面**：由开场工作面的整体视角进入三个相关资源组——平安家族角色、医疗专项图形、营销资源。类别共享一个展示空间，通过尺度和间距形成分组。保持图例原始比例；角色有共同底部基线，医疗图形有一致展示尺度。营销组只作代表预览，完整应用在04模块展开。

**内容组织**：默认同时看见三类资源与名称；点击某组后，在同一区域查看该组的更多原素材，其他组收为小预览。类别名称使用平面文字，不套一排胶囊。

**延续关系**：这组素材在03的生成方法和04的业务成果中再次出现，让访客能认出资源如何形成并被使用。

**来源**：36—38页。

### 03 生成方法：把技术作用说明白

**标题**：把业务需求，转成可控的生成方法。

**说明**：组织训练素材、关键词与模型定义，经过效果检查，再发布和开放调取。

**首要焦点**：模型训练过程及真实输出之间的关联。

**主画面**：按原稿“模型类型—训练过程—入库素材”组织三组空间。中间过程占最大面积，训练界面选可阅读局部；左右类别紧邻它，避免各自分散成信息墙。

**六个步骤**：收集提炼、打标设定、模型定义、效果测试、发布使用、开放调取。

**技术解释**：LoRA说明定向训练，ControlNet说明生成控制，C4D/Blender说明原3D创建。保留当时作品采用的方法，分别与真实角色、图形或模型截图关联。

**管理表达**：用本人目标设定与最终决策的职责解释资源建设方向。若展示某一技术选择的具体原因，需采用本人真实取舍；现阶段以已核对过程为主，不补造决定过程。

**交互**：查看一项原有模型案例，输入素材、过程与输出同步聚焦。连线只用于明确的一对一关系，优先邻近排列与步骤序号。

**来源**：39页，37页补充技术配合。

### 04 业务应用：看见资源服务了什么

**标题**：从素材储备，走向多业务应用。

**说明**：将资源应用于企业服务、体检活动、商城营销和医疗健康内容。

**首要焦点**：业务类别与真实应用画面。数字紧贴对应名称。

**主画面**：四列共享同一成果展示面；每列为业务名称、素材数量、代表成果。统一标题位置、数字基线与图片区域，通过留白分组，不分别套成四张相同的圆角卡片。

**数据**：

- 320+：ToB企业服务素材。
- 180+：体检活动类素材。
- 1000+：商城热促素材。
- 800+：医疗健康百科素材。

**管理表达**：本人主导资源方向与建设，结果体现团队资源的业务应用广度。上述数字保持素材数量口径，不衍生效率百分比，也不合计为另一项总指标。

**交互**：主动切换该业务的真实代表图，名称和数字固定。页面不自动快速轮播，便于阅读成果细节。

**来源**：40页。

### 05 视频流程：第三部分的主要展开段

**标题**：把视频制作，组织成一条完整流程。

**说明**：从业务内容、脚本与分镜，到关键帧、声音和动态镜头，完成筛选、组合与交付。

**本人职责**：我规划目标与方向、牵头组织推进，共同参与执行支持，并负责最终决策。

**首要焦点**：同一个真实案例从需求到成片的连续变化。

**主画面**：进入同一视觉体系中的制作工作面，采用“总览＋原位展开”。总览呈现四个阶段，每阶段一项中间产物；展开时保留当前阶段的名称和源素材位置，在右侧或下方增加详细内容。真实分镜、关键帧、动态镜头与成片形成可追踪关联，阶段顺序由邻近排列和清晰名称表达。按照实际素材归属匹配，不能用不同视频凑成一条生产链。

**阶段与九步对应**：

| 四阶段 | 原九步 | 默认展示 | 展开后展示 |
| --- | --- | --- | --- |
| 内容策划 | 1需求、2内容翻译、3分镜实现、4脚本修饰 | 需求摘要与分镜预览 | 真实脚本、分镜和提示词 |
| 视听资产 | 5关键帧、6拆分镜头、7声音生成 | 关键帧与角色/场景参考 | 同案例镜头拆分及声音准备 |
| 动态生成 | 8动态生成 | 对应动态镜头预览 | 同案例真实候选片源，及存在的检查说明 |
| 后期交付 | 9视频合成 | 成片 | 真实剪辑或音画组合材料 |

**成果口径**：原PDF为单月4组视频、800+组镜头；此前分享将800+描述为生成片源。现阶段成果写“4组视频 / 800+候选镜头片源”，周期与具体统计范围待口径统一后进入视觉稿。

**视频与动效**：成片由访客点击播放；流程首次进入仅轻量出现。展开由点击触发，状态可返回；不采用自动循环把分镜、截图与成片不停替换的方式。

**阅读方式**：默认状态即可理解完整流程，深读者可以逐阶段展开。手机端按四阶段顺序纵向阅读。

**来源**：41页；42页及此前视频分享补充中间产物。

### 06 方法沉淀：说明AI判断与管理价值

**标题**：把生成经验，沉淀为团队方法。

**说明**：以Skill组织脚本与分镜，将实践中的规则、检查项与问题处理经验保留下来。

**本人职责**：我负责最终提炼与总结，把共同实践中的经验整理为后续可复用的方法。

**首要焦点**：真实方法与输出的对应关系。

**主画面**：保留05的深色工作区，换为较安静的阅读构图。一侧展示Cursor Skill中的可读规则，另一侧展示实际生成的脚本或分镜，以及总结分享材料。代码只显示与输出直接相关的内容，不整屏堆代码。

**深度内容**：由此前提供的分享材料呈现一组“问题与处理方式”，优先采用长镜头拆为小动作、提示词冲突修正、候选镜头筛选等真实例子。以问题、判断、处理结果为主次，不再复制05的九步流程。

**AI理解如何被读到**：

- 业务适配：怎样将业务内容转成生成任务。
- 生成控制：怎样组织角色、场景、风格和镜头约束。
- 流程组织：怎样衔接文本、图像、声音、动态镜头和后期。
- 质量判断：怎样检查一致性和可用性，处理时间、成本及返工问题。

这些理解分别落实在03、05、06的实际内容中，不另外增加一个抽象的AI自评图。

**交互**：在真实问题示例之间主动切换，规则和说明在原位置成组更新。分享材料通过局部放大阅读，尚未提供的培训人数或场次不写入页面。

**来源**：42页；此前《动态视频AI分享》中的实践记录。

### 07 专业认可与三个重点项目的整体收尾

**标题**：让项目成果，获得专业认可。

**说明**：将专业认可与对应项目关联，完成近期重点工作的总结。

**首要焦点**：项目成果与专业认可的关系，随后归纳整体能力。

**主画面**：采用明亮、安静的成果展陈构图。统一栅格的年度成果索引与精选项目图例相邻，2023、2024、2025形成阅读顺序，奖项与项目名称成组；证书作为可查看的证据。让项目主体和结语承担视觉重量，证书细节主动放大阅读。

**对应关系**：

- 2023：一分钟诊所—GOOD DESIGN；可视化体检方案—GXA最佳创新奖。
- 2024：平安健康智慧医生工作台—IAI数智设计铜奖、KTK专业组UI设计类三等奖。两项奖合在同一项目中，保持与BianQue结尾已有证据的关联。

**归属**：用户本次确认的核心负责人职责适用于资源库与AI视频流程；奖项申报分工未单独确认，页面不把全部奖项写成本人独立主导获得。

**整体结语**：以业务为方向，把设计、团队与技术组织成持续交付的能力。

**收尾组织**：上方成果紧密成组，下方结语与简历、联系入口构成网页结束。小马辅助PDF只在补充资料区规划一个小型下载链接，文件以后采用用户重新提供的版本。

**交互**：点击查看证书原图；已有BianQue和体检条目可返回对应案例。无强制播放或数字滚动。

**来源**：43—47页与前三部分已确认内容。

## 4. 统一构图规则

- 母版为3840×2160，沿前两部分共同边距与栅格；开场角落页眉按已确认位置与字号。
- 左侧叙述与右侧内容标题共享起始高度；正文和画面上下间距以8px系统组织。
- 默认内容模块采用左侧简洁总述、右侧主体展开；04结果允许四列通栏，07整体收尾允许居中组织。
- 先采用三个主要文字档位：核心标题、模块标题、正文。数据模块可让大数字替代核心标题的大字档，避免同时出现多档大字。
- 英文采用Helvetica/Helvetica Neue无衬线，斜体用于少量强调；中文使用统一无衬线字体。
- 主标题原则上最多两行，副说明不拆成多个相距很远的句子。图注与对应图例紧邻，不单独漂浮在页面底部。
- 色彩随内容阶段变化：深色开场 → 浅色资源与应用 → 深色制作工作区 → 明亮成果收尾。颜色提案沿原稿蓝、深灰基底，与前两项目保持关联；具体色值在首屏试稿确认。
- 大背景按资源、生成、制作、成果的场景变化，采用原素材与秩序化排列；医疗人体背景不继续贯穿这一章节。
- 数字、+号、业务名称和图例保持一组。连线仅服务明确关系，不使用装饰竖线或让多组引线交叉。
- 原资源和截图等比置入，截取局部需有完整来源预览。禁止AI重绘真实UI和证书。
- 关键结论默认可见；素材选择、阶段展开及证书查看提供阅读深度，移动端可点击并顺序阅读。

## 5. 素材准备与构图顺序

先确认本规划，再做01开场与02资源体系的主构图，验证章节识别、文字比例、素材完整性及与上一部分的衔接；随后完成03—04、05—06、07收尾。

每个模块优先使用原PDF及已经提供的原素材。图例需要进一步放大时，下一轮从同源导出中取用清晰素材；缺失的脚本、候选镜头或代码局部不以生成图片冒充。

05与06若已有分享素材足以构成真实案例链路，直接整理使用；具体成员人数与量化效率不作为当前构图的前置条件。

静态主状态确认后再设计展开状态，最后统一实现动态网页。本轮前两个项目的视觉文件不修改。

## 6. 验收标准

1. 进入第三部分第一眼能看出新章节与本人负责人角色。
2. 能区分资源、生成方法、业务应用、生产流程、知识沉淀和专业认可。
3. 管理行动与相邻的资源或流程证据对应，AI方法与其输入、输出对应。
4. 每个模块有一个明确主视觉，图例比例和标题基线一致。
5. 数字保持原有统计含义，候选片源与最终成片不会混淆。
6. 与原作品集35—47页能够对照；第三部分完成三个重点项目的整体收尾。
