# 王峥个人作品集

面向 GitHub Pages 的纯静态个人简历与案例网站，入口文件为仓库根目录的 `index.html`。

## 页面

- 首页：个人定位、精选项目、方法与经历；
- BianQue 智能医生工作站；
- 体检履约平台体验升级；
- 设计管理与技术拓展。

## 动态效果

- 首页内容渐显与项目入口；
- BianQue 用户画像切换、指标计数与滚动渐显；
- 体检项目 3D 选购页切换、预约路径 GIF 正反向展开、报告状态切换；
- 设计管理项目资源轮播、开场卡片与光影、数据翻动、团队荣誉轮播；
- 四个本地视频弹窗播放；
- 全站统一项目菜单、页尾串联与减少动态效果适配。

全部运行时逻辑使用原生 HTML、CSS 和 JavaScript；没有 npm 依赖、外部 CDN 或构建步骤。

## 本地预览

可以直接打开 `index.html`，也可以在仓库根目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

仓库由 GitHub Pages 从 `main` 分支根目录直接发布，无需构建命令。

交互规划、页面确认记录和验收截图保存在 `docs/`。

- 部署审计：`docs/DEPLOYMENT-AUDIT.md`
- 完整文件清单：`docs/FILE-MANIFEST.tsv`
